# PC Shop Empire 3D

Yeni, sıfırdan geliştirilen 3D mağaza simülasyonunun teknik çalışma alanıdır.

- `Assets/`, `Packages/`, `ProjectSettings/`: Unity 6000.3.21f1 URP projesi.
- `SourceAssets/`: İleride üretilecek kaynak sanat, ses ve benzeri düzenlenebilir dosyalar.
- `Docs/`: Teknik kararlar, lisans ve provenans kayıtları.
- `Tools/`: Proje dışı yardımcı araçların kaynakları; üçüncü taraf binary tutulmaz.
- `../Builds/Local/`: Yerel test buildleri; Git çalışma ağacının dışında kalır.

Bu Git çalışma ağacı eski Electron oyununun kaynak kodunu içermez. Eski proje yalnız davranış ve veri göçü için salt okunur referanstır. UVCS ilk check-in'i uzak bağlantı reseti nedeniyle beklemededir ve aynı anda ikinci authoritative sistem olarak kullanılmaz. “PC Shop Empire 3D” geçici çalışma adıdır; nihai marka kararı değildir.
